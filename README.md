## 💻 시스템 요구사항

- **Node.js**: 16.x 이상 (권장: 18.x 또는 20.x)
- **npm**: 8.x 이상
- **OS**: Windows 10+, macOS 10.15+, Linux (Ubuntu 20.04+)
- **브라우저**: 최신 Chrome, Edge, Firefox, Safari
- **디스크 공간**: 약 500MB (node_modules 포함)

> Node.js 설치: https://nodejs.org/ko/download/

## 🛠️ 설치 가이드

### 1단계: 저장소 클론

```bash
git clone <repository-url>
cd Chatbot
```

또는 이미 받은 폴더로 이동:
```bash
cd Chatbot
```

### 2단계: 서버 의존성 설치

프로젝트 루트에서 실행:
```bash
npm install
```

설치되는 주요 패키지:
- `express` — 웹 서버 프레임워크
- `socket.io` — 실시간 양방향 통신
- `better-sqlite3` — 임베디드 데이터베이스
- `multer` — 파일 업로드
- `bcryptjs` — 비밀번호 해싱
- `jsonwebtoken` — 토큰 기반 인증

### 3단계: 클라이언트 의존성 설치

```bash
cd client
npm install
cd ..
```

설치되는 주요 패키지:
- `react` — UI 라이브러리
- `socket.io-client` — Socket.io 클라이언트
- `axios` — HTTP 통신
- `date-fns` — 날짜 포맷

### 4단계: 환경 변수 설정 (선택)

프로젝트 루트의 `.env` 파일을 확인/수정합니다:

```env
NODE_ENV=production
PORT=5000
JWT_SECRET=원하는-비밀-키로-변경하세요
```

> **⚠️ 운영 환경에서는 반드시 `JWT_SECRET`을 변경하세요!**

### 5단계: React 앱 빌드

```bash
npm run build
```

`client/build` 폴더에 최적화된 정적 파일이 생성됩니다.

## 📖 사용 방법

### 1. 회원가입

1. 브라우저에서 **http://localhost:5000** 접속
2. 노란색 로그인 화면에서 **[회원가입]** 탭 클릭
3. 다음 정보를 입력:
   - **아이디**: 영문/숫자 (고유해야 함)
   - **비밀번호**: 자유롭게 설정
   - **닉네임**: 다른 사용자에게 표시될 이름
4. **[회원가입]** 버튼 클릭 → 자동 로그인

> 💡 **다른 사람과 채팅하려면 친구도 회원가입을 해야 합니다.**
> 같은 컴퓨터에서 테스트하려면 시크릿/프라이빗 창에서 다른 계정으로 접속하세요.

### 2. 로그인

1. **[로그인]** 탭 선택
2. 아이디/비밀번호 입력 후 **[로그인]** 버튼
3. 토큰은 7일간 자동 유지 (다음 접속 시 자동 로그인)

### 3. 새 대화 시작

#### 1:1 대화
1. 좌측 상단 **✏️ 버튼** 클릭
2. 검색창에 친구의 아이디 또는 닉네임 입력
3. 결과에서 한 명을 클릭하여 선택
4. **[대화 시작 (1명)]** 버튼 클릭

#### 단체 대화
1. **✏️ 버튼** 클릭
2. 여러 사용자를 검색하여 선택 (선택된 사람은 노란 칩으로 표시)
3. 상단에 **그룹 대화방 이름** 입력 (선택사항)
4. **[대화 시작 (N명)]** 버튼 클릭

> 💡 같은 사람과의 1:1 대화방은 한 개만 존재합니다. 다시 시작하면 기존 방으로 이동합니다.

### 4. 메시지 보내기

채팅방을 선택하면 우측에 대화창이 열립니다.

#### 📝 텍스트
- 하단 입력창에 메시지 입력 → **Enter** 또는 **➤ 버튼**
- **Shift + Enter** = 줄바꿈

#### 🐹 햄스터 스티커
1. 입력창 왼쪽 **🐹 버튼** 클릭
2. 20종 스티커 패널이 열립니다 (4열 그리드)
3. 원하는 스티커를 클릭하면 즉시 전송

**스티커 목록:**
| | | | |
|:-:|:-:|:-:|:-:|
| 사랑가득 ❤️ | 무지개 🌈 | 빵터짐 😂 | 펑펑 😭 |
| 폭발화남 🔥 | 경악 😱 | 잠자기 😴 | 수줍 😊 |
| 쿨가이 😎 | 파이팅 💪 | 고민중 🤔 | 챔피언 🏆 |
| 축하파티 🎉 | 먹구름 🌧️ | 천사 😇 | 마법사 🧙 |
| 공주님 👑 | 안아줘 🤗 | 음악 🎵 | 게이머 🎮 |

#### 📎 파일/이미지/동영상 첨부 (대용량 지원)
1. 입력창의 **📎 버튼** 클릭
2. 파일 선택 (이미지/동영상/오디오/문서 등 모든 형식)
3. 채팅창 상단에 **진행률 바**가 표시됨 (속도·남은시간 포함)
4. 업로드 완료 시 채팅 메시지로 자동 전송
5. 받는 방식:
   - 🖼️ **이미지** → 클릭하면 라이트박스로 확대
   - 🎬 **동영상** → 채팅 안에서 바로 재생 (구간 이동 가능)
   - 🎵 **오디오** → 인라인 플레이어로 재생
   - 📎 **그 외 파일** → 클릭하면 다운로드 (확장자별 아이콘 자동 표시)

> 📦 **최대 파일 크기: 5GB** (기본값) — `.env`에서 `MAX_FILE_SIZE`로 자유롭게 조정
> ⛔ 보안상 실행 파일은 차단: `.exe .bat .cmd .com .scr .msi .dll .sh .app .deb .rpm`
> 자세한 사용법은 아래 [대용량 파일 / 미디어 공유](#-대용량-파일--미디어-공유) 섹션 참고.

### 5. 그룹방에 멤버 추가

1. 채팅방 우측 상단 **👥 버튼** 클릭
2. 현재 참여자 목록 확인
3. **[+ 대화 상대 추가]** 클릭
4. 사용자 검색 → **[추가]** 버튼

> 💡 1:1 대화방에 사람을 추가하면 자동으로 그룹방으로 전환됩니다.

### 6. 상대방 상태 확인

- **사이드바 프로필 사진 우하단의 초록 점** = 현재 접속 중
- **타이핑 표시** = "OOO님이 입력 중..." (자동 사라짐)
- **읽지 않은 메시지** = 채팅방 옆 **노란 배지** (숫자)

### 7. 로그아웃

좌측 상단 **🚪 버튼** 클릭.

### 업로드 진행률 UI

대용량 파일을 첨부하면 채팅창 상단에 실시간 진행 바가 나타납니다:

```
📤 movie_4K.mp4
   1.2GB / 3.5GB  ·  28.6MB/s  ·  남은시간 1분 22초          34.3%
████████████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
```

표시 정보:
- 파일명
- 현재 업로드된 용량 / 전체 용량
- **전송 속도** (KB/s, MB/s 자동 변환)
- **남은 예상 시간** (초/분/시간)
- **진행률 %** (소수점 1자리)

### 업로드 한도 조정

`.env` 파일에서 `MAX_FILE_SIZE`를 바이트 단위로 설정:

```env
MAX_FILE_SIZE=1073741824      # 1GB
MAX_FILE_SIZE=5368709120      # 5GB (기본값)
MAX_FILE_SIZE=10737418240     # 10GB
MAX_FILE_SIZE=53687091200     # 50GB
MAX_FILE_SIZE=107374182400    # 100GB
```

변경 후 서버를 재시작해야 적용됩니다.

> 💡 한도 확인용 API: `GET /api/upload/limits` (인증 필요)

### 동영상 스트리밍 (Range 요청)

서버는 `Accept-Ranges: bytes` 헤더와 HTTP 206 Partial Content 응답을 지원합니다.
이를 통해:
- 영상 중간으로 **시킹(탐색) 즉시 가능** — 전체를 다운로드하지 않음
- 대용량 파일의 **다운로드 재개** 지원
- 브라우저가 필요한 구간만 요청해 트래픽 절약

## ❓ 문제 해결 (FAQ)

### Q1. 포트 5000이 이미 사용 중이라고 나옵니다

다른 프로세스가 점유 중입니다. 다음 중 하나를 선택:

**A) 다른 포트 사용:**
`.env` 파일에서 `PORT=5001`로 변경 후 재실행.

**B) 점유 프로세스 종료 (Linux/macOS):**
```bash
kill $(lsof -ti:5000)
```

**Windows:**
```cmd
netstat -ano | findstr :5000
taskkill /PID <PID번호> /F
```

### Q2. `npm install` 도중 `better-sqlite3` 빌드 에러가 납니다

C++ 컴파일러가 필요합니다.

**Windows:**
```bash
npm install --global windows-build-tools
```

**macOS:**
```bash
xcode-select --install
```

**Linux (Ubuntu):**
```bash
sudo apt install build-essential python3
```

### Q3. 친구가 같은 와이파이에서 접속하려면?

서버를 실행한 PC의 IP 주소를 확인:
- Windows: `ipconfig`
- macOS/Linux: `ifconfig` 또는 `ip addr`

친구는 같은 네트워크에서 **http://[당신의IP]:5000** 으로 접속.
방화벽에서 5000번 포트 허용이 필요할 수 있습니다.

### Q4. 회원가입한 계정 정보를 모두 초기화하고 싶어요

서버 종료 후:
```bash
rm chatapp.db
rm -rf uploads/*
```
다시 시작하면 DB가 새로 생성됩니다.

### Q5. 업로드한 파일은 어디에 저장되나요?

프로젝트 루트의 `uploads/` 폴더에 UUID 파일명으로 저장됩니다.
원본 파일명·크기·타입은 DB에 기록됩니다.

### Q6. 비밀번호를 잊었습니다

현재 비밀번호 재설정 기능이 없습니다. DB에서 해당 계정을 삭제하고 재가입하세요:
```bash
sqlite3 chatapp.db "DELETE FROM users WHERE username='your_id';"
```

### Q7. HTTPS로 운영하고 싶어요

Nginx 등 리버스 프록시 뒤에 두는 것을 권장합니다. 또는 `https` 모듈로 직접 SSL 인증서를 적용해 `server/index.js`를 수정하세요.

### Q8. 모바일에서도 동작하나요?

반응형은 아직 최적화되지 않았습니다. 데스크톱 브라우저 또는 태블릿 가로 모드를 권장합니다.

### Q9. 5GB보다 큰 파일을 올리고 싶어요

`.env` 파일에서 `MAX_FILE_SIZE`를 바이트 단위로 늘리고 서버를 재시작하세요.
```env
MAX_FILE_SIZE=21474836480    # 20GB
```
디스크 공간과 네트워크 대역폭이 충분한지 확인하세요.

### Q10. 대용량 업로드 도중 끊기거나 멈춰요

- **서버 타임아웃은 30분**으로 설정되어 있습니다 (`server/index.js`). 더 큰 파일은 값을 늘려주세요.
- **클라이언트 axios timeout도 30분**입니다 (`ChatRoom.js` `handleFileUpload`).
- 와이파이가 불안정한 경우 유선 연결 권장.
- 리버스 프록시(Nginx 등) 뒤에 있다면 `client_max_body_size`, `proxy_read_timeout`도 함께 늘려야 합니다.

### Q11. 큰 동영상이 처음부터 다 받아야 재생되나요?

아니요. 서버가 **HTTP Range 요청을 지원**하므로 브라우저가 필요한 부분만 받아 재생합니다. 영상 타임라인 어디든 클릭하면 즉시 그 위치로 이동(seek)합니다.

### Q12. 업로드한 파일이 디스크를 많이 차지해요

`uploads/` 폴더를 주기적으로 정리하세요. 30일 이상 지난 파일 자동 삭제 예시 (Linux):
```bash
find /path/to/Chatbot/uploads -type f -mtime +30 -delete
```
> ⚠️ DB의 메시지 참조는 남아 있으므로, 삭제 후에는 해당 파일 메시지가 깨질 수 있습니다.

### Q13. `.exe` 파일을 꼭 보내야 합니다

보안상 기본 차단되어 있습니다. ZIP으로 압축해서 보내거나, `server/routes/upload.js`의 `BLOCKED_EXTENSIONS` 정규식을 수정하세요 (책임은 본인에게 있습니다).
